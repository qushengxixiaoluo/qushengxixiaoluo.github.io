PRD · SELF AS A PRODUCT

我，作为一个产品的说明书

介绍自己最好的方式，是像写 PRD 一样：说清楚服务谁、解决什么痛点、交付什么价值。以下就是这份说明书。

01

POSITIONING / 定位

产品思维 × 全栈工程

不只是把代码写对，更要把需求做对。我习惯先问三句话：用户是谁？痛点有多痛？最小可交付方案是什么？——然后用最短路径把它做出来、上线、拿反馈。

02

TARGET USERS / 目标用户

我服务这几群人

情绪需要出口的人 想留住每一天的人 想亲近古诗词的人 总怕漏掉安排的人 校园里的你我他 着迷新交互的探索者
03

PAIN POINTS / 核心痛点

我看到的问题

  • 专业心理支持门槛高、有距离感，情绪问题常无处安放；
  • 照片堆满相册却从不回看，日记总是坚持不下来；
  • 日程录入太繁琐，重要的事靠脑子记，容易漏、容易重复；
  • 读诗词的资料分散又枯燥，缺一份沉浸感；
  • 校园二手交易信息不对称，买卖双方都在碰运气；
  • 人机交互长期被困在一块玻璃屏幕里。
04

VALUE PROPOSITION / 价值主张

我交付的价值

  • 跨平台：Flutter 一次编写，多端运行；
  • 离线优先：不依赖网络，打开即用；
  • AI 原生：把大模型能力接进真实场景；
  • 可感知交互：手势、3D、动效，让操作有反馈。
PRODUCT MATRIX / 解决方案

痛点之下，是我交付的六款产品

每一个项目都不是「练手玩具」，而是对应一个真实痛点的最小解决方案。全部开源，可直接体验。

P01 · EMOTION COMPANION FLUTTER APP

情绪陪伴助手

DART · FLUTTER · OPENAI API

痛点 心理咨询有门槛、有距离感，日常的坏情绪却随时随地发生。
方案 轻量治愈系 Flutter 应用：AI 聊天 + 情绪分析，把温暖的心理陪伴装进口袋。
ai-chatbot emotion-analysis mental-health openai-api

P02 · 诗语 SHIYU FLUTTER APP

诗语 · 古诗词赏析

DART · FLUTTER · OFFLINE-FIRST

P05 · LIFESNAP 拾光手册 FLUTTER APP

拾光手册 · AI 照片日记

DART · FLUTTER · ANTHROPIC / OPENAI API

痛点 照片堆满相册却从不回看，写日记三分钟热度，坚持不下来。
方案 把每一天拍成一关闯关地图的 AI 照片日记：多源照片扫描 + AI 每日总结（双模型格式），批量断点续跑，吉卜力×糖果手绘画风。
ai-photo-diary anthropic-api openai-api daily-summary

P06 · EVENT CALENDAR FLUTTER APP

智能日程 · 事件日历

DART · FLUTTER · LOCAL-FIRST · AI
